01 / Flagship

Start here

These three projects best demonstrate the engineering behaviors current aerospace roles repeatedly ask for: modeling, implementation, integration, test, uncertainty, verification and technical communication.

PRJ-01
Active

GHOST-X: Occlusion-Tolerant Target State Estimation

ROS 2 · Raspberry Pi · IMM estimation · uncertainty-aware dropout behavior

Why it is flagship work

It combines estimation architecture, embedded execution, hardware measurement loss, deterministic software truth, closed-loop GNC and explicit claim boundaries. The current target-estimation path centers on a formal IMM estimator with a bounded GHOST-MH comparison; the portable attitude ESKF is a supporting component, not the headline tracker.

ASTRA-OS: Flight Software Assurance

C++17 flight core · Python ground tooling · command/telemetry · FDIR

Why it is flagship work

The project treats verification as architecture rather than cleanup: deterministic modes, command integrity, watchdog/health monitoring, FDIR, fault injection, Monte Carlo, sanitizer/static-analysis gates and requirement-to-test traceability.

AeroFrame-DT: Aircraft Fitting Stress Substantiation

Hand methods · FE correlation · allowables · fatigue · damage tolerance · digital thread

Why it is flagship work

It carries one synthetic, non-OEM aircraft fitting from load basis through margins, FE verification, fatigue/damage tolerance, manufacturing and change control. The project keeps the cases where its own assumptions failed instead of burying them.
