03 / RUN PROCEDURE

How the verification is executed

Not a screenshot demo. The repository rebuilds the environment, runs tests, checks retained evidence, executes C++ equivalence, rehearses operations, and can regenerate the frozen campaign.

1
Freeze configurationVersioned JSON inputs define scenario and acceptance thresholds.
2
Execute modelOrbit, relative navigation, GNC, 6-DOF and autonomy propagate the scenario.
3
Write evidenceEach campaign emits summaries, events, retained failures and provenance.
4
Cross-check implementationC++20 CW and controller outputs are compared against frozen Python vectors.
5
Gate the resultTests, evidence hashes and declared acceptance criteria must remain consistent.
